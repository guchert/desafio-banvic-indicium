# Desafio BanVic — Certificação Data Analyst | Indicium Academy

## Sobre o projeto

Este repositório reúne os entregáveis do desafio prático de certificação em Análise de Dados da **Indicium Academy**, baseado em um case fictício do setor bancário (BanVic). O desafio simula um cenário real de consultoria de dados, no qual uma Diretoria Comercial ainda não enxerga todo o potencial de uma cultura orientada a dados — cabendo à análise construir esse entendimento através de indicadores, visualizações e recomendações estratégicas.

## Etapas realizadas

- **Definição de KPIs e perguntas de negócio** voltadas à área comercial
- **Análise Exploratória de Dados (EDA)** em Python, com documentação dos principais achados
- **Prototipagem de dashboard** (mockup em Figma)
- **Desenvolvimento de dashboard executivo** em Power BI, aplicando boas práticas de storytelling e UX de dados
- **Documentação de regras de negócio**
- **Apresentação final**, com recomendações estratégicas orientadas a dados

## Ferramentas utilizadas

- **Python** (Google Colab) — análise exploratória de dados
- **Power BI** — construção do dashboard executivo
- **Figma** — prototipagem visual do dashboard
